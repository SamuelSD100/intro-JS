Introdução ao JavaScript

O que é JavaScript?

é uma linguagem de preogramação, muito utilizadas para criar aplicações interativas e sistemas de software.

Ele é responsavel por:

  • Responder a cliques
  • Validar formularios
  • Atualizar Conteudos
  • Buscar dados de APIs
  • Controlar o comportamento da aplicação

IMPORTANT: JavaScript não é Java

O que mais da pra fazer com JS?

  • Frontand
    • Criar interfaces interativas
    • Menus
    • Validações
    • Filtros
    • Animações
    • Dashboards
    • aplicações com React, Vue, Angular, Astro e etc.
  • Backand
    • Node.js
    • Criar APIS REST
    • Processar Requisições
    • Integrar com serviços e com banco de dados
  • Mobile/Desktop
    • Criar aplicativos
    • React Native e Electron
